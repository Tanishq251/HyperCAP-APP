Captioning Dataset for Vision Language Models

Abstract

We introduce HyperCap, the first large-scale hyperspectral captioning dataset designed to enhance model performance and effectiveness in remote sensing applications. Unlike traditional hyperspectral imaging (HSI) benchmarks, HyperCap integrates spectral data with pixel-wise textual annotations, enabling deeper semantic understanding. This dataset enhances model performance in tasks like classification and feature extraction, providing a valuable resource for advanced remote sensing applications. HyperCap is constructed from four benchmark datasets — Botswana, Houston 2013, Indian Pines, and Kennedy Space Center — and annotated through a hybrid approach combining automated and manual methods to ensure accuracy and consistency. Empirical evaluations using state-of-the-art encoders and diverse fusion techniques demonstrate significant improvements in classification performance. These results underscore the potential of vision-language learning in HSI and position HyperCap as a foundational dataset for future research in the field.

Key Highlights
1
New Dataset
First pixel-level HSI captioning benchmark. HyperCap provides one expert-refined caption per labeled pixel across all four datasets, totaling 21,237 annotations. Prior datasets like LDGNet offered only 2 template captions per class at patch level — HyperCap delivers orders-of-magnitude more granular and diverse descriptions.
2
Method
Dual-LLM + expert refinement pipeline. ChatGPT-4o and Mistral Large generate candidate captions in parallel for every labeled pixel. Three remote sensing experts then select and refine the most spectrally grounded output, with strict constraints: no class names, no functional language, no hallucinated world knowledge.
3
Result
Massive classification accuracy gains. Fusing HyperCap captions via BERT/T5 text encoders boosts overall accuracy by up to +27% on KSC (70.5→97.6%) and +23% on Indian Pines (76→99.4%) for DBCTNet. Even already-strong models like FAHM and 3D-ConvSST achieve 100% OA on Botswana with textual fusion.
4
Result
Resilient under extreme data scarcity. With just 3% of training labels, multimodal models using HyperCap captions stay above 98% OA — while vision-only baselines drop 4–5%. Caption supervision compensates for label scarcity in a way that spectral features alone cannot.
5
Analysis
No label leakage — captions are semantically additive. Ablation under text-only and image-only inputs shows consistent large performance gaps versus multimodal fusion, confirming captions encode complementary spectral–spatial semantics rather than hidden class-label signals. Text-only models score 15–29% below multimodal.
6
Task
New multimodal tasks opened for HSI. Beyond classification, HyperCap enables image captioning benchmarks (GIT leads with BLEU-1: 0.43) and cross-modal retrieval (IR ~62%, TR ~70%), revealing significant headroom and motivating domain-adapted HSI vision-language architectures.
